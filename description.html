See every attachment in a conversation without opening another application. Attachment Gallery lists the files in the message you are reading and in the rest of that conversation. Open a picture, a PDF, a sound or video clip, a text file, or the text of an Office document in Thunderbird. Nothing is uploaded. Key features:
  • One tab for the whole conversation, up to the latest 200 messages.
  • Filters for images, documents, and media.
  • Preview for images, PDF, audio, video, plain text, HTML, and Office documents (Word, Excel, PowerPoint, and OpenDocument).
  • Save a file, or open it in another application, from the preview.
Installation:
  1. In Thunderbird, open the menu and choose Add-ons and Themes.
  2. Click the gear icon and choose Install Add-on From File…, then select the .xpi. Or type Attachment Gallery in the search field, open this add-on, and choose Add to Thunderbird.
  3. When Thunderbird asks for access, choose Add.
This add-on needs Thunderbird 128 through 160. Open the gallery Select or open a message, then click Attachment gallery on the mail toolbar or on the message toolbar. A tab opens for that conversation. The header shows the subject. If the conversation is longer than 200 messages, the tab says it is showing the latest 200. The summary counts the files and groups them by kind. Buttons under it limit the list:
  • All — every file.
  • Images — pictures.
  • Documents — PDF, text, and Office files.
  • Media — audio and video.
  • Other — archives and anything else.
Pictures embedded in the message body are hidden until you turn on Show inline attachments. Preview a file Click a file. The preview opens in the same tab.
  • Images, PDF files, and audio or video clips play or display in the page, up to 25 MB.
  • Text and HTML are shown as text. HTML is shown in a frame that cannot reach the network.
  • Word, Excel, PowerPoint, and OpenDocument files show the text inside the document, up to 8 MB.
  • Archives and other types have no preview. Save them or open them in another application.
Save downloads the file. Open in application hands it to the program Thunderbird uses for that type. Close returns to the list.
