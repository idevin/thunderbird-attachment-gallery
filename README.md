# Attachment Gallery

See every attachment in a conversation without opening another application. Attachment Gallery lists the files in the message you are reading and in the rest of that conversation. Open a picture, a PDF, a sound or video clip, a text file, or the text of an Office document in Thunderbird. Nothing is uploaded.

This add-on needs Thunderbird 128 through 160.

## Install from a file

1. Download [`releases/attachment-gallery-1.0.0.xpi`](releases/attachment-gallery-1.0.0.xpi).
2. In Thunderbird, open the menu and choose **Add-ons and Themes**.
3. Click the gear icon and choose **Install Add-on From File…**.
4. Select the downloaded `.xpi` file.
5. When Thunderbird asks for access, choose **Add**.

## Install from add-on search

1. In Thunderbird, open the menu and choose **Add-ons and Themes**.
2. In the search field, type `Attachment Gallery` and press Enter.
3. Open the result for this add-on, by Ilya Devin, and choose **Add to Thunderbird**.
4. When Thunderbird asks for access, choose **Add**.
